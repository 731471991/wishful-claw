# Wishful Claw

基于 OpenCowork 架构的 Agent 编程软件，融合 KodaClaw 的记忆体系与人格体系设计。

## 技术栈

- 前端：React
- 后端：.NET 10

## 参考项目

| 项目 | 参考内容 |
|------|---------|
| OpenCowork | Agent Loop、工具链、模型 Provider、架构（Electron + .NET Sidecar） |
| KodaClaw | 记忆系统设计、人格系统设计 |
| OpenClaw.net | 记忆主动回忆机制、记忆工具化、上下文预算 |

## 规划

- 桌面应用（第一版，核心链路）
- App 聊天（轻量纯聊天，接入全能 App）
- 服务器版（可选）
