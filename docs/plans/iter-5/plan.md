## 目标

能管理项目，对话有历史记录。创建项目 → 开始对话 → 关闭应用 → 重开 → 能看到项目和历史对话。

## Plan 拆分

| Plan | 内容 | 独立验证 |
|------|------|----------|
| plan-001 | 后端 DB 层（SQLite + DbModule + 三张表 + CRUD） | `dotnet build` 通过 |

## 验证标准

创建项目 → 开始对话 → 关闭应用 → 重开 → 能看到项目和历史对话。
